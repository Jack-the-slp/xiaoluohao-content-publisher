# 小螺号内容发布

一台 Windows 电脑、自己的账号，用一个本地窗口编辑内容并分发到多个平台。图片、视频和文章使用各自已有的发布程序；提交前由你确认。草稿与登录状态保存在本机。

## 能做什么

| 内容 | 当前接入的平台 | 发布路径 |
| --- | --- | --- |
| 图片 / 图文 | 抖音、小红书、快手 | 本仓库的视频与图文上传器 |
| 视频 | 抖音、小红书、快手、视频号、B站 | 本仓库的视频上传器 |
| 文章 | 公众号、知乎、头条、B站专栏 | 本地 Markdown 草稿 → Wechatsync 浏览器扩展 |

图片和视频按平台逐个提交；B站视频需填写分区 ID。文章经 Wechatsync 同步为平台草稿，还需在平台后台检查并确认发布。平台页面会变化，上表表示接入了发布入口，不表示所有账号均已实发验证。

## Windows 本地启动

1. 安装 Python 3.12，并确保命令 `py -3.12` 可用。文章同步还需要 Node.js/npm。
2. 克隆或下载本仓库，双击 [启动小螺号内容发布.cmd](启动小螺号内容发布.cmd)。首次启动会在仓库内创建 `.venv`，安装 Python 依赖和 Chromium；如果有 npm，也会安装文章同步 CLI。后续启动会复用本地环境。
3. 打开窗口后，选择内容类型，填写标题、正文、话题和素材。先点“登录所选平台”，再点“确认后发布”。首次登录或二次验证由你在平台页面完成。
4. B站首次登录需在仓库文件夹的终端运行 `.venv\Scripts\python.exe sau_cli.py bilibili login --account 你的账号名称`。
5. 文章还需安装 [Wechatsync 浏览器扩展](https://github.com/wechatsync/Wechatsync)，并在 Chrome/Edge 中登录目标平台。扩展未连接时，文章草稿仍会保存在本地，不会算作已发布。

桌面快捷方式可以指向 `启动小螺号内容发布.cmd`；更换仓库位置后，请重新创建快捷方式。草稿保存在 `xiaoluohao_data/`，素材文件仍在你选择的原位置。

## 发布前检查

- 图片/视频：核对标题、文案、素材、所选平台和账号；点击确认框后才开始逐个平台提交。
- 文章：检查同步后的平台草稿，再在平台后台正式发布。
- 运行记录里的“命令完成”只代表工具执行结束；最终发布和审核状态以平台后台为准。

不要把 `cookies/`、`xiaoluohao_data/`、`conf.py`、`.venv/` 或平台账号文件提交到 GitHub。本仓库的忽略规则覆盖这些本地数据。
